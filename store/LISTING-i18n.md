# Store listing: translations

How to add them: Developer Dashboard → the item → **Store listing** → language menu at the top → pick the language
→ paste the description. The **summary** comes from `_locales/<lang>/messages.json` (`extDescription`), so it
appears automatically once the package with `_locales/` is uploaded. The name stays "CloudPage Navigator" in every
language. Screenshots can stay the English ones.
